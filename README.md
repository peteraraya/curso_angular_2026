# Curso de Angular 2026 🚀

Bienvenido al repositorio oficial del **Curso de Angular 2026**. Este proyecto contiene todo el material, ejercicios prácticos y proyectos desarrollados a lo largo del curso, estructurados para facilitar el aprendizaje progresivo del framework Angular desde sus fundamentos hasta conceptos avanzados.

## 🎯 Objetivo del Repositorio

El propósito principal de este repositorio es centralizar el código fuente, la documentación y los recursos educativos utilizados durante las sesiones del curso. Está diseñado para ser una guía de referencia rápida y un espacio de práctica para dominar Angular.

## 📁 Estructura del Proyecto

Actualmente, el repositorio está organizado en módulos de aprendizaje progresivos:

- `01-typescript-intro/`: Introducción y fundamentos de TypeScript, esenciales para el desarrollo moderno con Angular. Contiene conceptos básicos, tipado estricto, interfaces y clases.
- `material/`: Recursos adicionales, imágenes, diagramas y material de apoyo utilizado en las explicaciones de las clases.
- *(Se añadirán nuevos módulos y proyectos conforme avance el curso)*

## 🛠️ Tecnologías Utilizadas

- **Angular** (Versiones actuales)
- **TypeScript**
- **HTML5, CSS3 / SASS**
- **Node.js & NPM**

## 🚀 Cómo empezar

Cada módulo o proyecto dentro de este repositorio funciona de manera independiente. Para ejecutar cualquiera de ellos, debes navegar al directorio correspondiente e instalar las dependencias:

```bash
# Ejemplo para entrar al módulo introductorio
cd 01-typescript-intro

# Instalar las dependencias de Node
npm install

# Ejecutar el proyecto en modo desarrollo
npm start
```
